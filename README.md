# Cicatrizes-Verdes

Este projeto foi desenvolvido durante o curso técnico de informática como projeto conclusão de curso. Consiste em um site especializado em poluição e mudanças climáticas voltado para o ramo educacional, onde as pessoas podem consultar conteúdos relacionados a esses temas da natureza e poder compartilhar informações entre si. 

Desenvolvido por João Carlos, com a utilização de HTML, CSS, Javascript, Bootstrap e algumas APIs para enriquecer o conteúdo da plataforma.
